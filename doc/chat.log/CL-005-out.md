Отлично. Тогда я бы зафиксировал один из важнейших принципов проекта:

> **Ядро VTT пишется в консервативном подмножестве Ada'95.**
> 
> Более новые стандарты Ada используются только для оптимизаций, удобства разработки и платформенных расширений, но не являются обязательными для функционирования системы.

Это позволит сохранить совместимость с широким спектром компиляторов и платформ.

## Следующий шаг: определить минимальное ядро

Я бы начал не с графики и не с сетевого кода, а с формирования базовых пакетов проекта.


## Пакет конфигурации

Самый первый пакет:

```ada
package VTT_Config is
end VTT_Config;
```

Позже он станет точкой выбора:

- стандарта языка;

- компилятора;

- платформы;

- доступных модулей.

---

## Базовые типы

Например:

```ada
package VTT_Types is

   type Int8  is range -128 .. 127;
   type UInt8 is mod 2 ** 8;

   type Int16  is range -32768 .. 32767;
   type UInt16 is mod 2 ** 16;

   type Int32  is range -2 ** 31 .. 2 ** 31 - 1;
   type UInt32 is mod 2 ** 32;

end VTT_Types;
```

Не все старые компиляторы одинаково хорошо работают с реализациями из `Interfaces`, поэтому собственный слой типов может оказаться полезным.

---

## Идентификаторы объектов

Практически всё в VTT будет иметь ID:

- карты;

- токены;

- игроки;

- изображения;

- правила;

- сцены.

Например:

```ada
package VTT_Object_IDs is

   type Object_ID is new VTT_Types.UInt32;

   Null_Object_ID : constant Object_ID := 0;

end VTT_Object_IDs;
```

---

## Событийная модель

Я бы очень рано заложил систему событий.

Например:

```ada
package VTT_Events is

   type Event_Kind is
   (
      Event_None,
      Event_Token_Move,
      Event_Map_Load,
      Event_Dice_Roll
   );

end VTT_Events;
```

Позже она сможет использоваться:

- GUI;

- сетью;

- системой правил;

- редактором карт.

## Вопрос по именованию

Поскольку мы ориентируемся на старые компиляторы, я бы уже сейчас выбрал один стиль.

Например:

```ada
VTT_Config
VTT_Types
VTT_Events
VTT_Memory
VTT_Renderer
```

вместо

```ada
VTT.Config
VTT.Types
VTT.Events
```

Это ближе к эпохе Ada'83/Ada'95 и уменьшает вероятность проблем с экзотическими компиляторами.
